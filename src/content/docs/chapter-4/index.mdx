Chapter 3 drew workflows. This chapter is about the code inside them. Every scriptable task, action, custom decision, and form action is a script, and the quality of those scripts decides whether a workflow is easy to trust and change, or a puzzle for whoever opens it next.

Recipe 4.1 starts with the engine that runs your JavaScript, and why this book keeps to plain ES5.1. Recipe 4.2 turns scripts into a library of small actions that other workflows call, and shows how to change them without breaking anything. Recipe 4.3 steps outside JavaScript to Python, and to the environments that give a script its packages. The recipes still to come cover Node.js and PowerShell, logging, and the configuration elements that keep settings out of your code.

## The examples

The examples in this chapter are actions, so they all go in one module:

| Object | Name |
|---|---|
| Action module | `com.vcfguide.chapter4` |
| Workflow folder, for anything that needs one | **VCF Orchestrator Guide/Chapter 4** |
| Environment | `vcfguide-python-crypto` |

Like Chapter 3, the examples only read from the lab: the vCenter `vc01.vmw.lab` and its VMs, and the TLS certificate it presents. JavaScript samples are plain ES5.1. Python samples are ordinary Python 3.10.
